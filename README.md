# Medical Device Management & Maintenance System

A backend web application for managing medical devices and their maintenance workflows.

## Features

* Medical device management
* Maintenance workflow management
* RESTful API endpoints
* MongoDB database integration
* Middleware-based request handling
* Structured backend architecture

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* REST APIs

## Project Structure

```text
config/
controller/
middelware/
model/
routers/
app.js
```

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/doaaashraf-1/Medical_Device-Management-and-Maintenance-System.git
cd Medical_Device-Management-and-Maintenance-System
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file and add the required configuration values.

### 4. Run the application

```bash
npm start
```
